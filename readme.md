
# 🚀 Cours d'Initiation au Développement Web Moderne

Ce présent cours s'adresse à un jeune débutant (12 ans) souhaitant découvrir la création de sites web de manière ludique, moderne et concrète.

L'objectif est d'apprendre les fondamentaux du Web en construisant des projets réels (comme des cartes de profil de gamer ou des inventaires), tout en adoptant les meilleures pratiques actuelles des développeurs professionnels.

---

## 💡 Philosophie & Choix Pédagogiques

* **100 % Standards Modernes :** Focus sur les fonctionnalités natives actuelles du HTML5 et du CSS3 (Flexbox, Grid, Nesting, Variables, Popover API). Pas de bibliothèques lourdes ou de hacks obsolètes.
* **Pratique Immédiate :** Très peu de théorie pure ; chaque concept est immédiatement appliqué et validé par un projet visuel.
* **Zéro-JS pour démarrer :** Exploiter la puissance du CSS moderne pour créer des interfaces dynamiques et interactives sans complexifier l'apprentissage avec du code Javascript au début.
* **Outils Pros :** Prise en main directe de Visual Studio Code, de l'extension *Live Server* et du format Markdown pour la documentation.

---

## 📁 Structure du Manuel

1. **Chapitre 1 : Initiation & Les Fondations HTML/CSS**
   * L'inspecteur du navigateur, la structure `index.html`, le décryptage du raccourci `!`.
   * Le Modèle de Boîte (*Box Model*), les unités `rem`, les couleurs hexadécimales.
   * *Projet :* Premier composant visuel et carte de profil simple.

2. **Chapitre 2 : Les Moteurs de Mise en Page (Flexbox & CSS Grid)**
   * Aligner des éléments sur un seul axe avec `display: flex`.
   * Découper l'espace en tableau 2D avec `display: grid`.
   * *Projet :* La carte Gamer / Pokémon complète avec statistiques et bouton interactif.

3. **Bonus & Mini-Projets (Niveau 2)**
   * Menu sans JS (`popover`), grille d'inventaire automatique et effets 3D au survol (`hover`).

---
